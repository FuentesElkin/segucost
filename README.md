# SeguCost – Especificación de Requerimientos de Software

Repositorio de evidencias del proyecto de medio término de **Ingeniería de Software I**
(ESPOL).

Equipo T4. 

**Tutor académico:** Dr. Carlos Mera.

## Descripción del proyecto

**SeguCost** es un sistema web y móvil de gestión productiva, control de tiempos y costeo
industrial para **SEGUPLAST S.A.**, empresa de Guayaquil que fabrica fundas plásticas.
Hoy la empresa anota los pedidos a mano en un block de órdenes y no registra de forma
sistemática los tiempos, las pausas ni las mermas de la planta.
